③ 数据模型（存档新增两块，版本号不跳）

save = {
  version: 1, chars: {...}, daily: { wins: {...} },        // 现有不动
  codex: {                                                  // 新增，旧档就地补默认空对象
    cards:   { strike: 3, pry: 1, ... },                    // 卡牌id → 打出次数（含升级版？→ 不含，按基础卡归并）
    relics:  { shaft_pendant: 1, ... },                     // 遗物id → 拾取次数
    enemies: { rat_swarm: 7, ... },                         // 敌人id → 遭遇次数
  },
  stats: {                                                  // 新增
    chars: { prospector: { runs, wins, bestDepth, battles, dlWins: {1:2, 2:1} }, ... },
    lastDaily: '2026-10-23',                                // 最近每日通关日
  },
}
  • 写入时机：卡/遗物在获得时记（store/reward），敌人遭遇时记（battle 开始），局末结算写 stats —— 均挂在现有存档点之后，不新增存档频率。
  • 宽容合并：云存档 pull 时 codex/stats 按「数值取大」合并，与本档合并逻辑同层。
  • 成就零存储：全部运行时从 codex / stats / daily 派生，改成就文案不迁移数据。
