设计说明 —— 主页与选人页合并为一张封面：暗色井道（越往下越黑，呼应下潜）+ 顶部漏光光柱 + 三人物封面横排。每张封面 = 大立绘 + 名字 / 出身 + 刻痕档 + 一句话定位；未解锁的灰化加锁（解锁条件写在封面上）。 点封面选中（金环 + 「已选择」角标），DL 排 + 开始下潜收在底部，继续 / 每日 / 设置降级为小字链接。 落地范围：index.html 的 menu-main 改造成封面（选人页退役并入）；app.js 的 fillCharSelect / menuPage 改挂封面交互；Progress 解锁判定照旧。确认后进正式代码。
